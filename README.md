# MTA-STS for `eineweltladen-villingen.de`

## Motivation

This repository contains the required HTTPS endpoint for configuring the
[MTA-STS policy](https://learn.microsoft.com/en-us/purview/enhancing-mail-flow-with-mta-sts#how-to-adopt-mta-sts)
for incoming emails to the `eineweltladen-villingen.de` domain.
